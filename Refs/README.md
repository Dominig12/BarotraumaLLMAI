Publicized Barotrauma/LuaCs reference DLLs go here (not committed).

Run `tools/get-refs.ps1` (Windows) or `tools/get-refs.sh` (Linux/macOS), or download
`luacsforbarotrauma_refs.zip` from https://github.com/evilfactory/LuaCsForBarotrauma/releases/tag/latest
and extract it into this folder so that `Refs/Windows/DedicatedServer.dll` exists.

Use the refs that match the LuaCs version installed on your server.
